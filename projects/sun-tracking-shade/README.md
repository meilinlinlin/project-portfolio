# Smart Sun-Tracking Shade
## 太陽追蹤式遮光板控制裝置

本專題設計一套可依太陽位置與環境光線自動調整角度的智慧遮光系統，整合光感測器、太陽位置演算法（SPA）、雙軸伺服馬達與能源管理機制，使遮光板能依環境狀況進行水平與垂直方向調整。

系統同時整合太陽能、鋰電池與市電三種供電來源，並透過手機 App 提供系統監控與手動／自動模式切換功能。

## Project Highlights

- 雙軸智慧遮光與太陽追蹤
- 光感測器與太陽位置演算法（SPA）雙模式控制
- 太陽能、鋰電池與市電能源管理
- 手機 App 遠端監控與控制
- 完成系統整合、功能測試與研究成果發表
