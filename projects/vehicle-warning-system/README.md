# Large-Vehicle-Ahead Event Warning System
## 大型車之前車事件辨識與通報顯示對本車早期預警

本專題針對大型車遮蔽後方駕駛視野的問題，設計一套結合物件辨識、邊緣運算、微控制器與紅外線通訊的早期預警系統。

系統以前車作為感測與資訊轉譯節點，利用 Jetson Nano 執行 YOLOv5n 與 OpenCV 進行道路事件辨識，判斷弱勢用路人穿越及前前車緊急煞車等風險事件。辨識結果經 UART 傳送至 STM32，再透過車尾 LCD 顯示警示資訊，並以紅外線通訊將事件資訊傳送至後車端，最後由 LED 燈號與語音進行駕駛提醒。

## Project Highlights

- 使用 Jetson Nano 部署 YOLOv5n 進行即時物件辨識
- 結合 OpenCV 與 ROI 進行道路風險事件判定
- Jetson Nano 與 STM32 透過 UART 傳送事件編碼
- STM32 整合 LCD 顯示與紅外線發射／接收系統
- 建立弱勢用路人穿越與前前車緊急煞車警示機制
- 完成從影像辨識、事件判定、資料傳輸到駕駛警示的完整系統整合
- 進行辨識正確率、道路情境一致性與紅外線通訊穩定性測試

## Experimental Results

- 系統輸出正確率：87.6%
- 道路情境判斷 Accuracy：76.2%
- 紅外線通訊於測試範圍內接收成功率可維持 97% 以上
