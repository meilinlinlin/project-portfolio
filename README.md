### Large-Vehicle-Ahead Event Warning System
**大型車之前車事件辨識與通報顯示對本車早期預警**

結合 Jetson Nano、YOLOv5n、OpenCV、STM32 與紅外線通訊之車載早期預警系統，建立從影像辨識、事件判定至後車警示的完整流程。

主要技術：
- YOLOv5n 物件辨識
- OpenCV 與 ROI 事件判定
- Jetson Nano 與 STM32 UART 通訊
- STM32、LCD 與紅外線收發整合
